# firstmate-banner

Installed and updated by the pi-firstmate Pi extension. It draws the amber First Mate strip above the shown tab's panes and stays 0 px whenever that tab has no live First Mate session, so it adds no space to ordinary work.

Do not hand-edit this folder: a package update replaces only files whose content changed and keeps the previous copy under `~/.config/herdr-app/data/firstmate-banner/backups/`. To stop the banner, set `pi-firstmate.banner` to `false` and reload Pi, or delete the `firstmate-banner` block from the personal layout that uses it.
